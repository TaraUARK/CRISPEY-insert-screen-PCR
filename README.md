# CRISPEY Plasmid Insert Screen PCR Calculator

A single-page, in-browser Taq PCR master mix calculator for colony PCR screening of CRISPEY plasmid inserts.

- Choose the GAL or Z3 (estradiol) plasmid to set the forward primer (`pCR_GAL_Ins_Chk_F` / `pCR_Z3_Ins_Chk_F`) and expected product size (750 bp / 350 bp).
- Enter your samples; positive and negative controls are included automatically.
- Print or save step-by-step PCR instructions, or add gel images and save a final report.

Everything runs in the browser; nothing is uploaded. The whole tool is `index.html`.

## Hosting on GitHub Pages

Upload `index.html` to a repo, then Settings → Pages → Deploy from a branch → main / (root).
